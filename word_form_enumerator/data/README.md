# Data

These files were copied unchanged from the mk270 fork of Whitaker's Words
(`submodules/mk270`, commit `1f2f0fb`), so the enumerator runs without the
submodules:

- `DICTLINE.GEN`: the lexicon (stems, class, meaning)
- `INFLECTS.LAT`: the tagged endings
- `UNIQUES.LAT`: irregular forms that are spelled out in full
- `LICENCE.txt`: Whitaker's licence, which covers these files

To refresh them, copy the same four files from a newer checkout.
